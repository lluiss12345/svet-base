Трансфер: как заказать

Когда это нужно: гость хочет заказать трансфер из аэропорта/вокзала в отель или обратно.

С кем работаем

Отель сотрудничает с компанией «ТАКСИ Россия» (ТК Россия).

  • Телефон оператора: 330-40-40.
  • E-mail: info@tkrossiya.ru.
  • Машина: легковой автомобиль комфорт-класса Hongqi (Хончи), 1–3 человека.

Стоимость (в одну сторону)

Пример: Аэропорт → Отель с табличкой = 3 500 + 1 000 = 4 500 ₽.

Кто может заказать

  • Через отдел бронирования: звонок или письмо. Коллеги собирают информацию по шаблону и направляют письмо на ресепшн для оформления заявки.
  • Через стойку СПиР: по телефону, письмом или напрямую. Собираем информацию по шаблону.
  • Через 2ROOMZ: собираем информацию по шаблону.
  • От других служб отеля: собираем информацию по шаблону.
Все заявки на трансфер оформляются только посредством письма!

Как оформить

Шаг 1. Собери информацию по шаблону.
  • Аэропорт / Вокзал (откуда).
  • Дата.
  • Транспортное средство (Hongqi, 1–3 человека).
  • Имя гостя.
  • Номер телефона гостя.
  • Время прилёта / прибытия.
  • Номер рейса / поезда.
  • Количество гостей.
  • Количество багажа.
  • Комментарий: с табличкой / без.
  • Время подачи машины.
  • Дополнительная информация.
[МЕСТО ДЛЯ СКРИНШОТА: шаблон заявки на трансфер]
Шаг 2. Напиши письмо по шаблону «Заказ Трансфера».
В СПиР: напиши письмо → Подписи → «Заказ Трансфера».
Шаг 3. Дождись ответа.
ТК Россия подтверждает, что заявка принята и машина забронирована.
Шаг 4. После подтверждения — передай информацию.
  • Напиши pop-up «заказан трансфер, взять деньги (указываешь сумму трансфера)».
  • В Log Book накануне (за день до трансфера) оставь отметку «связаться с ТК Россия для подтверждения трансфера».
  • В Log Book в день трансфера укажи «№ брони и взять оплату за трансфер».
[МЕСТО ДЛЯ СКРИНШОТА: письмо-подтверждение от ТК Россия]

Оплата

  • Счета на компанию (за 2–3 рабочих дня) — ОБ.
  • Онлайн-ссылки (Русский Стандарт Эквайринг) — ОБ.
  • Наличными или по карте — СПиР.

Частые ошибки

  • Оформил заявку без письма. Заявка не принята.
  • Не собрал информацию по шаблону. ТК Россия не может выполнить заявку.
  • Не написал pop-up. Забыли взять деньги с гостя.
  • Не оставил отметку в Log Book. Не связались с ТК Россия для подтверждения.
