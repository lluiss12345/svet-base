Half Board и ужины: как продать и оформить

Когда это нужно: гость хочет ужинать в отеле. Есть два варианта: тариф Half Board (проживание + завтрак + ужин) или отдельная услуга «Ужин» (пакет).

Тариф Half Board

Что это:
Проживание + завтрак + ужин в формате фиксированного меню (салат, горячее, десерт, вода, чай/кофе). Замена горячего блюда — по запросу.
Где проходит ужин:
«Лобби бар», 1 этаж, с 18:00 до 21:30 (кухня до 21:30).
Стоимость:
1200 / 2400 руб. Детского тарифа нет.
Код услуги:
305 DINNER.
Продажа день в день недоступна. Может не быть продуктов. Если гость просит день в день — запроси подтверждение у сервис-менеджера ресторанной службы. Если продукты есть — продаём, нет — не продаём.

Как оформить Half Board в Fidelio

Шаг 1. Выбери тариф Half Board.
Стоимость тарифа рассчитана по формуле: BAR (завтрак + проживание, НДС 0%) + ужин (НДС 22%).
[МЕСТО ДЛЯ СКРИНШОТА: окно выбора тарифа в Fidelio с тарифом HALF BOARD RATE (HB)]
Шаг 2. Напиши в примечании разбивку.
Пример: «к оплате 4200 (3000 проживание + 1200 ужины)».
Шаг 3. Выставь billing instructions (рутинг, перенаправление).
  • Если оплата от физлица — создай новое перенаправление, оставь тот же номер, выбери код услуги 305.
  • Если оплата от юрлица — создай новое перенаправление, выбери профайл компании-плательщика, оставь тот же номер, выбери код услуги 305.
[МЕСТО ДЛЯ СКРИНШОТА: окно Billing Instructions с выбранным кодом 305]
Шаг 4. Возьми оплату раздельно.
Система автоматически начисляет пакеты с ужином и проживанием. Задача СПиР — взять оплату раздельно, из-за разницы ставок НДС.
Важно: если гость просит включить ужин в счёт за проживание — так нельзя. Будут два счёта: один за проживание, один за ужин.

Пакет «Ужин» (отдельная услуга)

Что это:
Гость может добавить ужин к любому тарифу. Формат: сет-меню. Накрытие в «Лобби бар», 1 этаж, с 18:00 до 23:00 (кухня до 22:30).
Стоимость:
1200 / 2400 руб. Детского тарифа нет. Код услуги: 305 Dinner.
Как оформить:
  1. Открой бронь, перейди в Package grid.
  2. Добавь пакет с ужином «DIN/Полупансион 1200/2400 выкл».
  3. Напиши в примечании разбивку.
  4. Выставь billing instructions (как для Half Board).
[МЕСТО ДЛЯ СКРИНШОТА: окно Package grid с добавленным пакетом DIN]

Снятие отчёта для ресторанной службы

Как снять отчёт:
  1. Miscellaneous → Report → 10206.
  2. Выбери «Отчет по пакетам (Отчет по завтракам) V(2)».
  3. Укажи даты.
  4. Выбери нужные пакеты (Полупансион, Завтрак и т.д.).
  5. Нажми Print.
[МЕСТО ДЛЯ СКРИНШОТА: окно отчёта 10206 с выбранными пакетами]

Частые ошибки

  • Продал Half Board день в день без подтверждения. Продуктов нет, гость остался без ужина.
  • Не написал разбивку в примечании. Бухгалтерия не может разобраться с НДС.
  • Не выставил billing instructions. Услуга начислена не туда.
  • Взял оплату одной суммой. Нельзя — раздельно из-за НДС.
