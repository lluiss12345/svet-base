Заселение через MAX ID (Госуслуги, QR-код)

Когда это нужно: гость хочет заселиться, используя цифровой паспорт в приложении MAX (через Госуслуги). Это удобно: не нужно отдавать бумажный паспорт, данные подтягиваются автоматически.

Важно: для заселения через MAX ID обязательно подтвердить личность гостя через Госуслуги. Без этого шага заселение невозможно.

Часть 1. Действия гостя

Шаг 1. Гость открывает MAX.
Гость заходит в приложение MAX и открывает раздел «Цифровой ID».
Шаг 2. Гость выбирает «Паспорт».
В разделе «Цифровой ID» нужно выбрать «Паспорт».
Шаг 3. Гость нажимает «Поделиться».
После нажатия на экране появится QR-код для заселения. Этот QR-код гость показывает тебе.
[МЕСТО ДЛЯ СКРИНШОТА: экран телефона гостя с QR-кодом из MAX]
Шаг 4. Гость подтверждает личность.
После того как ты отсканируешь QR-код (см. Часть 2), у гостя на телефоне появится запрос на подтверждение личности. Гость нажимает «Подтвердить». После этого сформируется дополнительный «динамический» QR-код для сканирования через Госуслуги.
[МЕСТО ДЛЯ СКРИНШОТА: экран телефона гостя с кнопкой «Подтвердить»]
Для свидетельств о рождении (дети): гость открывает раздел «Цифровой ID» → «Семья и дети» → «Свидетельство о рождении» → «Предъявить». Появится QR-код. Далее — «Подтвердить».

Часть 2. Действия администратора

Ты можешь отсканировать QR-код из MAX двумя способами. Выбери тот, который удобнее.

Способ 1. Через документ-камеру

Шаг 1. Открой карточку гостя в EMIS.
Найди гостя в системе EMIS (или создай новую карточку, если гость заселяется впервые).
Шаг 2. Нажми «Сканировать через документ-камеру».
Справа от кнопки «Сканировать» есть кнопка «Сканировать через документ-камеру». Нажми её.
[МЕСТО ДЛЯ СКРИНШОТА: карточка гостя в EMIS с кнопкой «Сканировать через документ-камеру»]
Шаг 3. Положи телефон гостя под сканер.
Под документ-камеру положи телефон гостя с открытым QR-кодом. Нажми «Сканировать QR-код».
Шаг 4. Данные появятся автоматически.
После сканирования данные гостя автоматически отобразятся в карточке EMIS.
[МЕСТО ДЛЯ СКРИНШОТА: карточка EMIS с заполненными данными гостя]

Способ 2. Через камеру личного телефона

Шаг 1. Открой карточку гостя в EMIS.
Найди гостя в системе EMIS.
Шаг 2. Нажми «Сканировать на телефоне».
Справа от кнопки «Сканировать» нажми «Сканировать на телефоне». На экране появится QR-код.
[МЕСТО ДЛЯ СКРИНШОТА: экран с QR-кодом для сканирования на телефоне]
Шаг 3. Отсканируй QR-код камерой телефона.
Наведи камеру личного телефона на QR-код на экране. Телефон направит тебя на камеру EMIS.
Шаг 4. Отсканируй QR-код гостя через камеру EMIS.
Через камеру EMIS отсканируй QR-код с телефона гостя. Данные отобразятся в карточке.
[МЕСТО ДЛЯ СКРИНШОТА: камера EMIS, направленная на QR-код гостя]

Часть 3. Подтверждение личности через Госуслуги

Это обязательный шаг. Без подтверждения личности через Госуслуги заселение через MAX ID не считается завершённым.
Шаг 1. Открой Госуслуги.
На рабочем компьютере или телефоне открой портал Госуслуг.
Шаг 2. Нажми «Госкан».
В правом верхнем углу нажми «Госкан» и выбери «Сканировать от лица организации».
[МЕСТО ДЛЯ СКРИНШОТА: меню Госкан с пунктом «Сканировать от лица организации»]
Шаг 3. Отсканируй динамический QR-код гостя.
Отсканируй тот QR-код, который появился у гостя после подтверждения личности (см. Часть 1, Шаг 4).
Шаг 4. Проверь результат.
На экране должно отобразиться «Личность подтверждена». После этого можно продолжать заселение по стандартной процедуре.
[МЕСТО ДЛЯ СКРИНШОТА: экран Госуслуг с надписью «Личность подтверждена»]

Частые ошибки

  • Не подтвердил личность через Госуслуги. Заселение через MAX ID не завершено. Гость может остаться без регистрации.
  • Отсканировал статический QR-код, а не динамический. Для подтверждения личности нужен именно динамический QR-код.
  • Не проверил, что данные в EMIS совпадают с документом. Всегда сверяй, что подтянулось.
