Апгрейд номера: как посчитать и оформить

Когда это нужно: гость хочет номер выше категорией, чем забронировал. Или отель сам предлагает апгрейд (например, при перегрузе).

Главное правило: стоимость апгрейда считаем через тарифную сетку, разницу — по тарифу BAR.

Как посчитать стоимость

Шаг 1. Выставь период дат.
В Fidelio выстави сразу необходимый период дат под апгрейд. Разница стоимости между категориями по дням может отличаться.
Шаг 2. Поставь галочку «Stay View».
Она показывает итоговую стоимость по выбранному периоду проживания.
[МЕСТО ДЛЯ СКРИНШОТА: окно Rate Selection с галочкой Stay View]
Шаг 3. Посчитай разницу по тарифу BAR.
Вычти изначальную сумму номера из суммы за категорию «выше».
Пример: для апгрейда со STD до SPR вычитаем из 12800 – 10800 и получаем 2000 — это разница, которую должен доплатить гость (если номер оплачен).
[МЕСТО ДЛЯ СКРИНШОТА: тарифная сетка с выделенными категориями STD и SPR]

Как оформить в брони

Шаг 1. Открой бронь.
Внутри брони в поле Rate Room type оставь изначальную категорию номера.
Шаг 2. Поменяй Room type.
В поле Room type поставь категорию, до которой делаешь апгрейд.
[МЕСТО ДЛЯ СКРИНШОТА: окно брони с полями Rate Room type и Room type]
Шаг 3. Оставь комментарий.
Оставь pop-up заметку о том, что был сделан апгрейд, и допиши сумму, которую добрали с гостя.
Шаг 4. Начисли услугу в биллинге.
Не забудь начислить услугу апгрейда в биллинге (Payments).
[МЕСТО ДЛЯ СКРИНШОТА: биллинг с начисленной услугой апгрейда]

Частые ошибки

  • Посчитал разницу не по BAR. Гость доплатил неправильную сумму.
  • Не поставил Stay View. Не увидел итоговую стоимость за период.
  • Забыл про комментарий. Потом никто не помнит, почему номер другой категории.
  • Не начислил услугу в биллинге. Гость уехал, доплата не прошла.
