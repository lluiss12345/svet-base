Walk-in: заселение день в день

Когда это нужно: гость приходит без брони (или звонит в день заезда) и хочет заселиться сегодня. Бронь создаётся и заселяется в один день.

Что НЕ считается Walk-in: продление проживания (гость уже живёт у нас и продлевает) — это не Walk-in, это продление (отдельная статья). Walk-in — это именно новая бронь, созданная и заселённая день в день.

Как оформить Walk-in

Шаг 1. Проверь наличие номеров.
Посмотри в Fidelio, есть ли свободные номера на сегодня. Если нет — предложи гостю другой вариант или другой отель.
Шаг 2. Создай бронь.
Создай новую бронь в Fidelio. Укажи:
  • Даты заезда и выезда.
  • Категорию номера.
  • Тариф.
  • Количество гостей.
Шаг 3. Укажи источник.
В поле «Source Code» выбери WalkIn. Это важно — иначе система не будет считать эту бронь как Walk-in, и она не попадёт в отчёт.
[МЕСТО ДЛЯ СКРИНШОТА: окно создания брони с полем Source Code = WalkIn]
Шаг 4. Засели гостя по стандартной процедуре.
Дальше — как обычное заселение: проверка документов, регистрационная карта, оплата, ключ (смотри статью 1.1).

Отчёт по Walk-in (дважды в месяц)

Каждый сотрудник СПиР должен заполнять свой отчёт по Walk-in два раза в месяц:

  • За первую половину месяца — до 15-го числа.
  • За вторую половину — до 30-го числа.
Как найти свои Walk-in в Fidelio:
  1. Открой Fidelio. В разделе поиска выбери Arrival → Between и укажи нужные даты.
  2. Добавь фильтр Source Code → Equal to → WalkIn.
  3. Добавь фильтр Created By → Equal to → твоя фамилия.
  4. Нажми All. Система покажет все твои Walk-in за период.
[МЕСТО ДЛЯ СКРИНШОТА: окно поиска в Fidelio с тремя фильтрами (Arrival, Source Code, Created By)]
Как заполнить файл учёта:
В файле учёта Walk-in заполняй строго по форме:
  • ФИО — строчными буквами (НЕ КАПСОМ).
  • Даты проживания — в формате дд/мм/гггг – дд/мм/гггг.
  • Цена — за первую ночь проживания, в числовом формате (например, 5050,00).
  • Бонус 5% и -13% рассчитываются автоматически.
Как выгрузить список в Excel:
  1. В списке Walk-in нажми правой кнопкой мыши на любое место.
  2. В открывшемся окне убери галочку Fit Page Width.
  3. В выпадающем списке выбери Excel Document.
  4. Нажми Export.
[МЕСТО ДЛЯ СКРИНШОТА: окно Print Grid Parameters с выбранным Excel Document]
Важно: учитываются только те бронирования, которые созданы под твоим логом в Fidelio. Если ты заселил гостя, но бронь создал кто-то другой — это не твой Walk-in.

Частые ошибки

  • Забыл указать Source Code = WalkIn. Бронь не попадёт в отчёт, бонус не начислят.
  • Не заполнил отчёт вовремя. До 15-го и до 30-го числа — строго.
  • Записал ФИО капсом. Форма требует строчные буквы.
  • Указал цену за все ночи, а не за первую. В файле учёта — цена за первую ночь.
