Работа с ключами iLocks

Когда это нужно: ты кодируешь ключи для гостей.

Вход в систему

Перейди на сайт (закреплён на каждом ПК).
Логин: 78126793373
Пароль: 202508
URL: http://10.160.19.35:9981
[МЕСТО ДЛЯ СКРИНШОТА: окно авторизации iLocks]

Кодирование ключа

Шаг 1. Двойным кликом перейди на нужный номер.
Шаг 2. Заполни поле «Фамилия» гостя.
Вписывай что угодно (для идентификации).
Шаг 3. Нажми «Заселить».
[МЕСТО ДЛЯ СКРИНШОТА: окно заезда гостя с полем «Фамилия»]
Шаг 4. В опциях выбери «Добавить карту».
Шаг 5. Укажи количество карт.
При необходимости заблокируй предыдущие карты.
Шаг 6. Жди звукового сигнала от кодера.
Если карт две — жди два сигнала.
[МЕСТО ДЛЯ СКРИНШОТА: окно добавления карты]

Чтение карты

Шаг 1. На главном экране нажми кнопку «Считать карту».
Шаг 2. Приложи карту к кодеру и жди данных.
[МЕСТО ДЛЯ СКРИНШОТА: информация о карте]

Установка времени выезда

Шаг 1. Кликни на значок календаря и на время.
Шаг 2. Нажми кнопку «Продлить» и магнити ключ.
[МЕСТО ДЛЯ СКРИНШОТА: календарь с выбором времени выезда]

Частые ошибки

  • Не дождался звукового сигнала. Карта не закодирована.
  • Не указал количество карт. Выдал меньше, чем нужно.
  • Не установил время выезда. Ключ работает дольше, чем нужно.
  • Не заблокировал предыдущие карты. Старые ключи всё ещё работают.
