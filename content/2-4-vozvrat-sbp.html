Как сделать возврат по СБП

Когда это нужно: гость оплатил через СБП (по QR-коду или по ссылке), а потом передумал. Ты возвращаешь деньги по СБП.

Главное правило: возврат по СБП делается только на тот же Source ID (номер исходной оплаты), с которого была оплата. Нельзя вернуть на другую карту или другой номер телефона.

Что подготовить

  • Гость должен быть рядом.
  • Паспорт гостя (страницы 2 и 3).
  • Чек об оплате (с Source ID — 19 цифр).

Шаги

Шаг 1. Проверь, через какой банк была оплата.
СБП может быть через терминал ВТБ или Русского Стандарта. Возврат — через тот же.
Шаг 2. Уточни у гостя все детали.
Спроси, с какого банка платил, на какой номер телефона. Сверь с чеком.
Шаг 3. Открой биллинг гостя в Fidelio.
Payments → введи сумму с минусом → комментарий «Возврат по СБП: причина возврата» → Post.
[МЕСТО ДЛЯ СКРИНШОТА: биллинг с проведённым возвратом по СБП]
Шаг 4. Проведи возврат через терминал.

Через терминал Русского Стандарта:
  1. Нажми цифру «0».
  2. Выбери «Операции СБП».
  3. Выбери «Возврат СБП».
  4. Введи пароль 000000.
  5. Нажми зелёную кнопку.
  6. Введи сумму.
  7. Введи номер исходной оплаты (Source ID, 19 цифр с чека оплаты).

Через терминал ВТБ:
  1. Нажми цифру «0».
  2. Нажми цифру «9» (возврат СБП).
  3. Введи номер исходной оплаты (Source ID, 19 цифр).
  4. Введи сумму к возврату.
[МЕСТО ДЛЯ СКРИНШОТА: экран терминала с операцией возврата СБП]
Шаг 5. Распечатай терминальный чек.
Один — себе, второй — гостю.
Шаг 6. Фискальный чек обязательно отдай гостю.
Шаг 7. Собери пакет документов.
  1. Копия паспорта гостя (страницы 2 и 3).
  2. Квитанция на возврат (из Fidelio) + подпись гостя.
  3. Счёт (Folio) с возвратом.
  4. Терминальный чек.
Шаг 8. Отнеси в офис.
В лоток «Возвраты».

Сроки возврата

Деньги приходят в течение 3–5 рабочих дней, иногда до 2 недель (зависит от банка).

Частые ошибки

  • Вернул через не тот терминал. Не пройдёт.
  • Неверный Source ID. Возврат уйдёт не туда или не пройдёт.
  • Забыл минус в Fidelio. Система записала как оплату.
  • Не отдал фискальный чек гостю. Гость не сможет подтвердить возврат.
