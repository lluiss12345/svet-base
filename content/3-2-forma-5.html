Форма №5: как заполнить и распечатать

Когда это нужно: гражданин РФ заселяется в отель, и его нужно поставить на регистрационный учёт. Форма №5 — это анкета, которую мы отправляем в МВД.

Главное правило: форма №5 заполняется на каждого гостя, подлежащего регистрационному учёту. Если гость с пропиской СПб/ЛО — форму не заполняем (см. статью 3.1).

Как заполнить

Шаг 1. Открой EMIS.
Найди гостя в системе EMIS.
Шаг 2. Заполни данные.
Внеси:
  • Фамилия, имя, отчество.
  • Дата рождения, пол.
  • Место рождения (страна, регион, район, город, населённый пункт).
  • Гражданство.
  • Документ, удостоверяющий личность (вид, серия, номер, кем и когда выдан, код подразделения).
  • Место жительства (страна, регион, район, город, населённый пункт, улица, дом, корпус, квартира).
  • Прибыл (дата).
  • Выбыл (дата).
  • Зарегистрировал (дата).
[МЕСТО ДЛЯ СКРИНШОТА: заполненная форма №5 в EMIS]
Шаг 3. Распечатай форму.
Нажми «Печать» → выбери форму №5.
Шаг 4. Поставь подпись.
Гость ставит подпись в форме (если требуется).

Если адрес регистрации не пропечатывается

Шаг 1. Сохрани анкету в папку «гости с неверным адресом прописки».
Шаг 2. Преобразуй PDF в Word.
Используй конвертер.
Шаг 3. Отредактируй адрес вручную.
Шаг 4. Распечатай.
[МЕСТО ДЛЯ СКРИНШОТА: исправленная анкета в Word]

Если гость по военному билету

Шаг 1. В EMIS выбери «Временное удостоверение гражданина РФ».
В графе «Удостоверение личности» выбери этот тип документа.
Шаг 2. Впиши данные из военного билета.
Шаг 3. Сохрани анкету в PDF.
Шаг 4. Преобразуй в Word.
Шаг 5. Поменяй название документа.
С «Временное удостоверение личности» на «Военный билет».
[МЕСТО ДЛЯ СКРИНШОТА: анкета с изменённым названием]

Куда девать форму

  • Граждане РФ: форма №5 + сопроводительное письмо → в МВД (через почту или электронно).
  • Иностранцы: уведомление о прибытии + копии документов → в МВД (отдельная статья).

Частые ошибки

  • Заполнил форму на гостя с пропиской СПб. Не нужно.
  • Не исправил адрес в EMIS. Анкета ушла с ошибкой.
  • Не поменял название документа для военного билета. Анкета выглядит как временное удостоверение.
  • Не распечатал форму. Гость остался без регистрации.
