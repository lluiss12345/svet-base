Распределение номеров (Room allocation)

Когда это нужно: перед заездом гостей нужно присвоить им номера. Обычно это делает старший смены или администратор вечером на завтрашний заезд.

Главное правило: не присваивай номера «наугад». Учитывай пожелания гостей, группы, семейные пары, VIP.

Порядок действий

Шаг 1. Начни с бронирований с нашего сайта.
Это брони от «ТРЭВЕЛ ЛАЙН ПРО ООО» (TravelLine).
Шаг 2. Отсортируй брони по CRS номеру.
Сверь последние цифры. Если они совпадают — бронирования сделаны в один момент и с одного устройства. Такому гостю даём номера поближе.
[МЕСТО ДЛЯ СКРИНШОТА: список броней с сортировкой по CRS Reservation Nr.]
Шаг 3. Отсортируй по ФИО гостей.
Если на заезде есть гости с одной фамилией (возможно, одна семья) — даём номера рядом.
[МЕСТО ДЛЯ СКРИНШОТА: список гостей с сортировкой по имени]
Шаг 4. Сбрось все фильтры и отсортируй по ФИО и CRS номеру.
Это финальная проверка.
Шаг 5. Если есть группы — прочитай групп-инфо.
Перед присвоением номеров группе внимательно прочитай групп-инфо. Начни присваивать номера одной из групп (если их несколько), отсортировав её в поле «Group».
[МЕСТО ДЛЯ СКРИНШОТА: окно с фильтром по Group]
Шаг 6. Когда все группы распределены — назначь номера оставшимся гостям.
Индивидуалы — в последнюю очередь.

Что учитывать при распределении

  • VIP-гости. Проверь пометки в профайле. Некоторым гостям нельзя менять номер.
  • Гости с животными. Номера на 5 этаже в приоритете: 508, 509, 510, 511, 513 (STD), 505, 506 (SPR), 507, 512, 514 (LUX).
  • МГН (маломобильные гости). Номера с поручнями и без порогов: х16 и х18 на 5–9 этажах.
  • Семьи с детьми. По возможности — рядом или в одном номере (если категория позволяет).
  • Коннект-номера. *02 и *03 на 6, 7, 8, 9 этажах — смежные. Если просят — учитывай.

Частые ошибки

  • Присвоил номера, не прочитав групп-инфо. Группа с особыми пожеланиями осталась недовольна.
  • Не учёл VIP-пометки. VIP-гостю достался номер, который нельзя менять.
  • Поселил гостя с животным на этаж, где животных не селят. Проблемы с другими гостями.
  • Не проверил МГН. Гость с ограниченными возможностями получил номер без поручней.
