Парковка: инвалиды (бесплатно)

Когда это нужно: гость с инвалидностью хочет припарковаться бесплатно.

Главное правило: бесплатная парковка для инвалидов — только на специально отведённых местах. И только если автомобиль зарегистрирован в Федеральном реестре инвалидов. Наличие инвалидности у гостя или статус сопровождающего не даёт права на бесплатную парковку.

Как проверить

Шаг 1. Гость обращается на ресепшн.
Шаг 2. Проверь наличие машины в реестре.
Зайди на сайт checkvehicle.sfri.ru (или через Госуслуги — раздел для инвалидов). Введи данные автомобиля.
[МЕСТО ДЛЯ СКРИНШОТА: страница проверки ТС в реестре]
Шаг 3. Если авто в реестре — выбирай тариф МГН в Парконике.
Парковка будет бесплатной.
Шаг 4. Если авто не в реестре — парковка платная по общим тарифам.
Объясни гостю, что льгота действует только для автомобилей, зарегистрированных в Федеральном реестре.

Где находятся места для инвалидов

На парковке есть специально отведённые бесплатные места для МГН. Они обозначены разметкой.

Частые ошибки

  • Дал бесплатную парковку без проверки реестра. Нарушение.
  • Дал бесплатную парковку, потому что у гостя есть инвалидность. Нельзя — авто должно быть в реестре.
  • Не объяснил, почему нельзя бесплатно. Гость недоволен.
