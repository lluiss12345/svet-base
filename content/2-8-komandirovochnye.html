Командировочные гости: чеки, счета, закрывающие документы

Когда это нужно: гость приехал в командировку. Ему нужны документы для бухгалтерии: чек, счёт, акт. Тут есть нюансы, которые важно знать.

Способы оплаты

Наличный (фискальный метод оплаты):
Карта / наличные / QR-код.
Безналичный (не фискальный метод оплаты):
Оплата по ссылке / на сайте / через агрегаторы / от компании по Б/Н.

Отображение в системе

Оплата гостем при заезде:
Гарантия: «Не гарант. / Non Guaranteed» или «Кред. карта / Guaranteed by CC».
Метод оплаты: «Cash» или «MasterCard Offline».
Оплата по безналичному расчёту:
Гарантия: «Компания / Guarant. by Company» или «Турагент / Guaranteed by Agent».
Метод оплаты: «Cityledger».
[МЕСТО ДЛЯ СКРИНШОТА: окно брони с методом оплаты CityLedger]
Важно! Обязательно обращай внимание на примечания в бронировании и на всплывающие (pop-up) заметки. В брони может быть указан метод оплаты CityLedger (безналичный расчёт), но при этом оплачены по Б/Н будут только первые сутки. Остальное гость доплачивает при заезде.

Чеки

Фискальные чеки:
  • Чек авансового расчёта — первичный чек за оплату денежной суммы в счёт предстоящих услуг. Не является отчётным документом (нет информации об оказанной услуге).
  • Чек окончательного расчёта — выбивается в момент выезда гостя. Это обязательный отчётный документ для командировочных. Включает перечисление оказанных услуг за период.
Терминальные чеки:
Два чека из терминала при оплате картой (один для нашей отчётности, второй — гостю).
Онлайн-чеки:
Чек, который приходит гостю при оплате на сайте / по ссылке.

Когда выдаём счёт

Выдаём счёт:
  • Оплата наличным расчётом на стойке (частично или полностью).
  • Оплата на нашем официальном сайте или по ссылке.
Не выдаём счёт:
  • Оплата через агрегаторы — Яндекс, Озон, Островок и др. Оплата приходит через посредника, счёт напрямую гостю выдать не можем.
  • Оплата от компании — корпоративная стоимость гостям не разглашается. Единственное, что можем предложить — справка о проживании без указания стоимости.

Закрывающие документы

Кто готовит:
Закрывающие документы (акт выполненных работ, счёт-фактура, акт сверки) готовит бухгалтерия. Это занимает время.
Важно: бухгалтерия работает полностью через ЭДО. Документы оформляются только после выезда. На руки гостям ничего не выдаётся.

Частые ошибки

  • Выдал счёт гостю, который оплачивал через агрегатор. Нельзя — оплата пришла через посредника.
  • Разгласил корпоративную стоимость. Нельзя — это коммерческая тайна компании-плательщика.
  • Пообещал закрывающие документы на руки. Бухгалтерия работает через ЭДО, на руки ничего не выдаётся.
