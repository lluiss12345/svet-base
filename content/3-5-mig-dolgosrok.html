Постановка на учёт иностранцев: долгосрок (через МВД)

Когда это нужно: иностранец заселяется в отель на долгосрочное проживание. В этом случае ставим на учёт через МВД.

Главное правило: пакет документов готовится отдельно на каждого иностранца. Сопроводительное письмо — для каждого отдельно.

Комплект документов для МВД

  • Уведомление о прибытии.
  • Копии всех страниц паспорта с отметками.
  • Виза (может быть электронная).
  • Миграционная карта.
  • Регистрация с предыдущего места пребывания (если гость в РФ более 7 дней).
  • Сопроводительное письмо (для каждого иностранца отдельно).
  • Копия выписки из реестра ФСА (для каждого иностранца).
  • Копия паспорта Столяровой Л.Н. (для каждого иностранца).
  • Копия доверенности Столяровой Л.Н. (для каждого иностранца).
  • Опись вложения.

Шаги

Шаг 1. Собери документы гостя.
Паспорт, виза, миграционная карта, регистрация с прошлого места. Сделай копии всех страниц с отметками.
Шаг 2. Сформируй уведомление о прибытии в EMIS.
Печать на обеих сторонах. Поставь печати и подписи.
Шаг 3. Сформируй сопроводительное письмо.
Для каждого иностранца — отдельное письмо. Укажи ФИО, даты заезда-выезда.
[МЕСТО ДЛЯ СКРИНШОТА: сопроводительное письмо для МВД]
Шаг 4. Приложи копии документов.
Копия паспорта Столяровой Л.Н., копия доверенности, копия выписки из реестра ФСА — на каждого гостя.
Шаг 5. Сформируй опись вложения.
Заполни опись Почты России.
Шаг 6. Отправь в МВД.
Пакет документов отправляется в МВД через почту или электронно (по регламенту паспортиста).

Что делать с уведомлением об убытии

Уведомление об убытии просто печатаем и кладём на стол паспортисту.

Сроки

Уведомление о прибытии должно быть направлено в орган миграционного учёта не позднее рабочего дня, следующего за днём заселения гостя.

Частые ошибки

  • Не сделал копии документов на каждого гостя. Пакет неполный.
  • Забыл сопроводительное письмо. Без него пакет не примут.
  • Не приложил копию доверенности. Паспортист не сможет представлять интересы отеля.
  • Не отправил вовремя. Нарушение сроков миграционного учёта.
