Программа лояльности: как зарегистрировать гостя (сканер, QR)

Когда это нужно: гость хочет вступить в программу лояльности или уже имеет карту и хочет, чтобы заезд засчитался.

Если гость ещё не в программе

Шаг 1. Предложи зарегистрироваться.
Дай гостю QR-код (на стойке, на тейбл-тенте) или ссылку на сайт nordhotels.ru.
Шаг 2. Гость заполняет анкету.
Вводит телефон, имя, фамилию, пол, дату рождения, email. Нажимает «Получить карту».
Шаг 3. Гость сохраняет карту в кошелёк.
Для iPhone — Apple Wallet. Для Android — Google Pay. Важно: установку карты нужно доводить до конца, сохранять на телефон. Иначе карта не засчитается.
[МЕСТО ДЛЯ СКРИНШОТА: экран телефона с картой в Apple Wallet]

Если у гостя уже есть карта (нужно засчитать заезд)

Шаг 1. Открой сканер на левом компьютере.
Зайди в браузер, переключи раскладку на английскую.
Шаг 2. Отсканируй QR-код карты гостя.
Наведи камеру телефона (или сканер) на QR-код в приложении гостя.
Шаг 3. Введи пин-код.
Пин-код: 2048.
[МЕСТО ДЛЯ СКРИНШОТА: экран сканера с вводом пин-кода]
Шаг 4. Пропиши «1» в строчке, нажми «Ок».
Заезд засчитан.
[МЕСТО ДЛЯ СКРИНШОТА: экран после успешного сканирования]

Добавление карты в профайл гостя в Fidelio

Шаг 1. Добавь номер карты в карточку гостя.
Открой бронь → Edit → Guest Card Info → New → Type «NH Nord Hotels» → введи номер карты → Ok.
[МЕСТО ДЛЯ СКРИНШОТА: окно Guest Card Info с номером карты]
Шаг 2. Добавь информацию по карте и ссылку в общие заметки по гостю.
Открой бронь → Edit → Notes → New → Category GLO «Общие заметки по гостю» → вставь ссылку из браузера и напиши номер карты.
[МЕСТО ДЛЯ СКРИНШОТА: окно Notes с ссылкой и номером карты]

Норма карт

Для отдела СПиР установлена норма карт за месяц (индивидуальная и общая). У каждого отеля свой файл Excel для учёта карт: FO → Программа лояльности → Отчет по картам Месяц. Внутри файл поделён на листы, каждый лист — на администратора СПиР («Фамилия Имя»). По итогам месяца подводится итог, затем — денежное вознаграждение. За неисполнение общей нормы отдел могут оштрафовать.

Если карта не работает

Напиши письмо в отдел маркетинга: pl@vedenskyhotel.ru (Ольга). Укажи проблему: номер карты, что нужно (восстановить ссылку, засчитать предыдущие заезды, обновить номер карты в системе).

Частые ошибки

  • Не довёл установку карты до конца. Карта не засчиталась.
  • Не ввёл пин-код. Заезд не засчитан.
  • Не добавил карту в профайл гостя. При следующем заезде не найдём.
  • Не выполнил норму карт. Отдел оштрафован.
